# 🪨📄✂️ Rock Paper Scissors

A simple **Rock Paper Scissors** game built with Python.

Play against the computer and see who wins! 🎮

## 🎮 How to Play

Choose one of the following:

* `0` → 🪨 Rock
* `1` → 📄 Paper
* `2` → ✂️ Scissors

The computer randomly chooses one of the three options, then the program determines the winner.

## 🏆 Game Rules

* 🪨 Rock beats ✂️ Scissors
* 📄 Paper beats 🪨 Rock
* ✂️ Scissors beats 📄 Paper
* Same choice → Draw 🤝

## 🛠️ Built With

* 🐍 Python
* `random`
* Lists
* `input()`
* `if / elif / else`
* Conditional logic
* List indexing
